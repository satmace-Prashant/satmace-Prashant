This repository contains a robust end-to-end automation test suite built using Playwright, an open-source Node.js library for browser automation. Playwright enables fast, reliable, and scalable UI testing for modern web applications across Chromium, Firefox, and WebKit browsers.

The objective of this project is to automate critical user journeys and validate application functionality through efficient and maintainable test scripts. This ensures high product quality, faster release cycles, and increased confidence during deployment.
